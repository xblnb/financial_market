## 一、v3.2（t14）：F2 / F3 / F4 / D1 / F1

### [F2-a] §3.3 新增「标度口径说明」
`ΔP_AC = λ_eff(D_ref)·(|Q|/Q0)^γ·mid`，其中
`D_ref = clamp(|Q|, Q0_FLOOR=1e4, Q_MAX_REF=2e6)`、`λ_liq = clamp(D_ref/1e6, 0.05, 20)`、`λ_eff = 0.05·λ_liq`。

⇒ **总标度分段**：
| 区间 | λ 行为 | 总标度指数 | 性质 |
|---|---|---|---|
| `|Q| < 1e4` | 落在地板 `λ_liq=0.05` | `γ` | 次线性 |
| `1e4 ≤ |Q| < 2e6` | `λ_liq ∝ |Q|` | `1+γ ∈ [1.5, 1.7]` | **超线性** |
| `|Q| ≥ 2e6` | λ 封顶 | `γ ∈ [0.5, 0.7]` | 次线性 |

实测（相互印证的两组独立证据）：
- engine-dev：`2.5e4 → 1.0e5` 放大 **4.0838** 倍；`1.0e5 → 4.0e5` 放大 **9.06** 倍
- test-engineer（独立 harness）：`Q=5e4` **×8.4259**；`Q=1.25e5` **×9.4260**
- 规格 §3.3 旧表值 `5e4 → 2.5e5` = **×4.53**（**同一模型的结果，不是实现偏差**）

写法要求：把上表与实测值一起写进 §3.3，并在表后加一句
「本表为模型定义的结果；`λ_liq` 随 `|Q|` 增长是"深度侵蚀"建模选择的直接后果，与经典平方根律的次线性不同（见 DEV-AC-1）。」

## 二、v3.3（t16）：γ@ADV≤0 口径 + DG-4c② 恒等式 + DG-2a 补充观测

### [G1] 钉死 `ADV ≤ 0` 时 γ 的退化口径
**裁决**：`ADV ≤ 0`（冷启动 / 新存档首日）时 **`γ = γ_max = 0.7`**。
依据：① §3.1 公式 `γ = 0.5 + 0.2·sat((Q/ADV)/2)` 在 `ADV→0` 时的**数学极限**就是 `γ_max`；② 与"市场越薄 ⇒ 冲击指数越陡"的意图一致；③ 与用户"冷启动巨额卖单必须砸动价格"的诉求一致。

文档要求：
- 在 §3.1 的 γ 定义处**显式写出** `ADV ≤ 0 ⇒ γ = γ_max` 的退化规则与上述理由（现文档只为 λ 写了 F-AC-3 退化，**γ 缺失**）。
- 在 DG-2a 的分段标度断言与 DG-2b 巨单判据中，**补写 `ADV=0` 场景的取值口径**（引用 t15 刷新后的标定表 ADV=0 行）。
- 登记实现侧现状：`MarketImpact.gammaAC` 原为 `return acGammaMin`（γ=0.5），**已判为偏离规格**，由 **t15** 修正（改为 `γ_max` 并刷新标定表 ADV=0 行的改前/改后两列）。

### [G2] DG-4c② 的 `dividendYield` 判据改为**恒等式断言**（不再用区间近似）
事实：§8 DG-4c② 原文写 `dividendYield ≈ 0.01~0.03`，实测上界 **0.0498**（1.66× 文字上限）。根因：该文字是**旧基线**（`0.01 + Math.random()*0.02`）的近似残留；现行生成链为 `dividendYield = 0.01 + netMargin × 0.2`，而 `netMargin ∈ [0.02, 0.35]` ⇒ 理论域 **`[0.014, 0.08]`**。

裁决与写法：
- **主判据改为恒等式**：`|dividendYield − (0.01 + netMargin×0.2)| ≤ 1e-9`（这才是"勾稽自洽"的机械证明）。
- 区间 `[0.014, 0.08]` 降为**辅助观测**（探针原用宽域 `[0.005, 0.05]` 不算错，但不再作为主判据）。
- 立一条**判据书写纪律**：「凡能写成恒等式的判据一律写恒等式；`≈` 区间仅用于无法写成恒等式的量。」
